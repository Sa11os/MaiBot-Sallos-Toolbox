# 架构与扩展约束

`plugin.py` 提供工厂；`app.py` 装配服务并处理加载、配置更新和卸载。各功能在 `features/<name>/`
拥有独立组件、模型、服务和数据目录。跨功能通用能力应有至少两个实际调用者。

外观分四层：Pydantic 模型校验、预设服务与存储、隔离页面编辑器、Dashboard 资源适配器。
预设 revision 用于检查并发修改；全站应用以最近一次确认操作为准。

适配器发现目录 → 检查版本与布局标记 → 检查目录所有权 → 写入脚本 → 备份入口 → 原子安装入口。
入口最后提交。插件数据保存主题与备份；公共资源仅发布当前主题和预览回退主题。
每 8 秒更新租约，浏览器每 2 秒读取一次，30 秒缺少新租约时撤销样式。预览最长 20 秒，
浏览器使用单调时钟计时。停用发布空主题并按精确标记恢复入口，保留其他程序对入口的改动。
专属静态资源保留在原位置，供已打开页面读取恢复状态；新页面从已恢复入口加载。

主题脚本临时切换根元素的视觉样式属性，撤销后还原。原生导航行为由宿主状态管理，
插件覆盖已适配的布局与样式锚点。登录与初次配置页面保留宿主外观。

Python 模型生成前端 schema、默认值和内置预设，避免参数漂移。`build_webui.py` 将页面编译为
单文件 HTML，并生成独立全站脚本。`webui.json` 使用官方 v2 字段；所有变更经绑定的静态 API，
应用、预览和恢复由宿主确认。

视觉参考 SallosWorkbench 的浅灰底、白色面板、系统字体、蓝色强调与柔和圆角。
Apple Design 用于即时按压反馈、直接滑块预览与减少动态效果；UI/UX Pro Max 用于标签、焦点、
触控尺寸、对比度与窄屏检查。

新增功能创建独立目录，在 app.py 显式装配，API 以功能名为前缀。前端放入同名功能目录，
在构建脚本中注册，并同步核心行为验证、说明与版本。手写 Python/JS/CSS 单文件控制在 300 行以内，
入口控制在 80 行以内。生成产物保留可重建来源。
