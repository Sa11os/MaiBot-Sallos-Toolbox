# Sallos 工具箱 0.2.1

修复首次安装期间配置只有启用开关、缺少 plugin.config_version 而暂停加载的问题。
ZIP 现在附带从配置模型生成的完整 config.toml；源码提供 config.example.toml。
打包仅使用模型默认值，开发者本地运行配置保持私有。

现有 0.2.0 安装可直接修复：在配置页面的 [plugin] 节补上以下一行，保留其余字段并保存：

```toml
config_version = "1.1.0"
```

配置结构版本为 1.1.0，插件发行版本为 0.2.1。保存后按管理页状态重载插件或重启麦麦。
升级时宿主会保留原配置，因此已有无版本配置应先补版本号。

新增 5 项回归检查覆盖官方 Runner 版本检查、管理页先启用场景、ZIP 默认配置、旧配置值保留及打包隔离。
沿用 Dashboard 1.9.9 的适配范围和静态资源接入机制；全站外观需 Dashboard 目录可写。
NAS 由使用者自行操作。
