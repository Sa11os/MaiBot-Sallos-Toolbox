# Sallos 工具箱 0.2.0

新增全站外观工作台，支持侧栏位置和展开宽度、顶栏高度、内容留白、配色、字体与卡片细节。
提供三套内置风格、个人预设、20 秒全站预览和恢复功能。代码按功能、服务、存储与适配器拆分。

下载附件中的插件 ZIP，在 MaiBot 插件管理上传，按宿主提示重启并启用后刷新整个 Dashboard。
当前适配 Dashboard 1.9.9，开发基线为 MaiBot 1.3.15、SDK 2.16.0。
已安装同 ID 插件时，按官方管理页流程先卸载旧版；更新前备份插件数据。

插件会备份并修改 Dashboard 页面入口，安装独立外观脚本；需要静态目录写入权限。
应用与全站预览同步到同一服务器的所有浏览器。版本或权限检查失败时，工作台展示具体原因。
详见仓库 docs/compatibility.md。NAS 部署由使用者自行完成。

本地已验证官方前端安装包、SDK 注册、官方页面协议、预设持久化与冲突处理、安装恢复、桌面和窄屏。
浏览器联调使用真实插件服务及模拟宿主 HTTP 接口；目标 NAS 的版本与权限仍需安装后核对。
