# Sallos 工具箱 0.2.4

首页响应式铺满可用内容区，减少宽屏留白和纵向滚动。

- 按实际容器宽度自动使用四列、三列、两列、单列布局，图表在空间充足时成对显示。
- 卡片改用内容自然高度，首页移除嵌套滚动，资讯列表保留自身滚动区域。
- 首页单独使用全宽，其他页面继续遵循内容宽度设置。
- 原生编辑模式保留，卡片顺序、隐藏状态及已存布局数据保持原样。

本地官方前端验证覆盖 2560、1920、1440、1280、900、390px 六种宽度，以及右侧侧栏、大字号、编辑与恢复。
默认数据下，2560×1032 和 1920×1080 完整展示；1440×900 主区域滚动余量约 78px。
更多卡片、较大字号及额外内容会增加自然滚动高度。

保留此前的导航接缝、按钮对齐与侧栏交互修复。适配 Dashboard 1.9.9，配置结构版本保持 1.1.0。
在插件管理中上传 ZIP 更新，按宿主提示重启后刷新整个 Dashboard；NAS 由使用者操作。
